# 🎙️ Jarvis Voice Assistant (Python + Streamlit)

An AI-powered voice assistant built using **Streamlit**, **SpeechRecognition**, and **gTTS**.

## 🚀 Features
- Voice command recognition 🎧  
- Wikipedia search 📚  
- System control (open apps, web search, etc.) 💻  
- Real-time speech response 🗣️  

## 🛠️ Tech Stack
- Python 3.13  
- Streamlit  
- SpeechRecognition  
- gTTS  
- Wikipedia API  

## 💡 How to Run
```bash
python -m streamlit run "voice assistant.py"
